# Docs

Este repositorio contiene una pequeña aplicación web estática (HTML, CSS y JavaScript) para gestionar una lista de tareas (todolist).

Estructura:

- index.html — página principal
- src/css/styles.css — estilos
- src/js/app.js — lógica del cliente (almacenamiento en localStorage)

Cómo usar:

1. Abrir `index.html` en un navegador (o desplegar con GitHub Pages).
2. Añadir tareas, marcarlas como completadas o eliminarlas. Las tareas se guardan en el almacenamiento local del navegador.

- Desplegar con GitHub Pages
